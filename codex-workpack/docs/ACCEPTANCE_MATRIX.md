## 達標裁決

- `A01–A38`、`A40–A43` 皆需實際證據才可列產品完成；`A39` 僅在對外主張「某版本課本收錄」時適用，否則應記 `NOT_APPLICABLE` 並限制對外宣稱。
- `A36` 已可由工作包單獨執行，但**不代表 A37/A38**。
- 未經實機執行，A29/A31/A32/A33/A41/A42 不得填 PASS。
- 若暫無出版與資料權限，保留 `BLOCKED`，不得以 CLI `--allow-pending` 冒充正式過關。
- 發布前另執行 `node codex-workpack/tools/check-release.mjs`；其成功不代替本表的實機與人工證據。工作包契約測試通過不能將遊戲 A35/A37 等項目直接填 PASS。
