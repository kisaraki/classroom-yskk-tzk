# 實作計畫 M0 → M5：工作分解、依賴與交付門檻

依照 `CODEX_SPEC.md` v1.3 的 M1–M5 執行；此處新增 **M0 安全盤點**。每階段先檢查現況，若已有功能請整合／測試，不要重做或覆蓋。

## M0：倉庫盤點／安全整合（第一優先）

**輸入**：倉庫目前工作樹、`codex-workpack/`、Git 分支與權限資訊。

**任務**：
- [ ] 記錄 `pwd`、`git status --short`、`git branch --show-current`、README、現有 AGENTS.md 與入口檔。
- [ ] 列出 HTML/CSS/JS/Data/Tests 的現存檔案和用途，辨識現有架構與能重用的部分。
- [ ] 調查 Pages 部署來源（如無權限則列 `UNKNOWN`），確認 repo subpath 是否會影響資源。
- [ ] 檢查是否有未提交更動、個資或現有測試；不得自動重設工作樹。
- [ ] 執行工作包驗證；將結果寫入 `docs/REPORT_TEMPLATES.md` 定義的倉庫盤點報告。

**完成門檻**：有實際盤點與增修計畫；未取得倉庫權限時須明確標記 `BLOCKED`，可在可存取的工作樹繼續實作但不能虛稱推送。

## M1：核心頁面、互動骨架及平板介面

**依賴**：M0；可採純測試夾具暫時驗證流程，但不得將夾具發布當正式 500 題。

**任務**：
- [ ] 專案根目錄 `index.html`、CSS、ES Modules 入口及 Canvas，不須 npm 打包。
- [ ] 以相對路徑載入靜態資源；在子路徑情境測試，封存錯誤訊息供排查。
- [ ] 首頁顯示標題、操作說明、五關概覽、玩家欄位、Start；名稱長度 1–16 字素，驗證後才能 Start。
- [ ] 實作內建虛擬鍵盤：數字 0–9、A–Z、常用中文字、預設名稱、空白、刪除、清除與切換頁籤；不可依賴實體輸入法。
- [ ] 支援 iPad/Android 橫向 4:3、16:10、16:9，100dvh/safe-area，不露捲軸；縱向鎖定提示。
- [ ] HUD：名稱、關卡、倒數、成語、逐字注音、釋義、目標序號，以及固定四格碰撞進度（COMPLETED/CURRENT/PENDING），P/R/A 觸控按鈕。
- [ ] 進度四格可用測試狀態渲染，並在 DOM/ARIA 上清楚區分三種狀態。

**交付**：首頁＋HUD＋Canvas、鍵盤模組與測試、畫面尺寸截圖或測試記錄。
**門檻**：無實體鍵盤能輸入／刪除；四字字卡永不消失或遮擋；資源可於專案子路徑載入。

## M2：真實物理引擎及姿態／搖桿控制

**依賴**：M1 的 Canvas 與輸入介面。

**任務**：
- [ ] 固定世界座標（建議 1280×720）、Canvas 縮放、DPR 上限與 ResizeObserver。
- [ ] 主球「我」、四種物件：targetPost/targetBall/distractorPost/distractorBall。
- [ ] 原生固定步 1/120 秒更新（半隱式 Euler 或等效穩定積分），速度／加速度／阻尼／反彈常數集中。
- [ ] 圓對圓碰撞：質量／逆質量、速度衝量、重疊修正；球對牆碰撞；post 必須固定。
- [ ] 非重疊初始配置與有限步備援；避免穿牆、卡住、NaN、長時間震動。
- [ ] 感測器 Start 原生點擊中首個 await 前要求權限；不能授權／無值時自動搖桿，顯示模式。
- [ ] 校準、低通濾波、死區、橫向正反握姿方向；搖桿 Pointer Events 多點觸控、失焦清零。
- [ ] 桌機方向鍵／WASD 測試輔助；不同幀率下相同固定步給出相近運動。

**交付**：物理純計算模組、控制器、碰撞接觸事件、物理及輸入測試。
**門檻**：真實碰撞可觀察且測試可重現；拒絕感測器仍可完整操作，無 CSS 假物理。

## M3：五關完整規則與狀態一致性

**依賴**：M2、正式 `contracts/levels.json` 映射及狀態機。

**任務**：
- [ ] 依每關固定色碼、秒數、完成條數、柱／球數目建立邏輯設定；啟動時自校驗。
- [ ] 每題四個目標（charIndex 0..3）、指定干擾物；只主球直接接觸正確目標計入。
- [ ] 文字進度僅以 `nextIndex` 衍生，錯撞不加分、閃爍與提示，避免每步重複判定。
- [ ] 同字成語按物件 ID 與 charIndex 區別，連續一個物理步最多完成一個字。
- [ ] 正確碰撞吸收物件，HUD 原字保留；完成四字顯示 4/4，再切新題 0/4。
- [ ] 一次遊戲選 19 條不重複成語；題組及佈局 seed 供本關 A 重試完全重現。
- [ ] 倒數開始／逾時／最後時刻命中優先序；關卡推進與五關通關總結。
- [ ] P 暫停／恢復、R 確認後全重來、A 每關確認後最多三次；取消無消耗。
- [ ] READY／PLAYING／IDIOM_CLEAR 在隱藏頁面、切換方向、系統權限提示時自動暫停；保存 resumeState、準備倒數及切題回饋剩餘時間，前景橫向時手動返回原狀態。
- [ ] 命中、錯誤、完成的動畫／音效可關閉音效，不能讓顯示取代邏輯。

**交付**：可用隔離測試題組完整跑完五關；自動化測試結果；與固定規格表逐欄比對。
**門檻**：76 次正確字序收集、19 題無重複、五關固定物件數、HUD 與規則不漂移，P/R/A 測試通過。

## M4：500 條正式資料與教育審查

**依賴**：M3 能消費正確的 `idioms_500.json` 結構；此階段不允許以假資料為正式交付。

**任務**：
- [ ] 沿用 `codex-workpack/data/idioms_500_selection.json` 原始 500 個 ID／詞目；不得自行換成另一批。
- [ ] 取得合法的教育部《成語典》可下載本機資料，**不得爬官方頁面**；紀錄檔案來源／版本／授權／取得方式。
- [ ] 若來源欄位對應不同，先檢查 `tools/import-idioms.mjs` 的映射規則，再進行匯入；不可套錯導致詞義誤植。
- [ ] 產出正式資料：四個逐字注音、完整可引用釋義／合法原創說解、難度與追溯來源欄位。
- [ ] 保留原始官方說解不改作；如另有教學提示請設獨立欄位並經審查。
- [ ] 建立根目錄 `data/idiom_linguistic_review.csv` 每筆核校紀錄：字音、釋義、來源、審核人員、日期及 `content_sha256`；從工作包複製實際核校紀錄，不可造假簽核，內容變更須重審。
- [ ] `node codex-workpack/tools/validate-idioms.mjs --data ./data/idioms_500.json --allow-pending` 通過結構檢查。
- [ ] **人工真正完成**核校後，設定狀態 `APPROVED`，以 `node codex-workpack/tools/validate-idioms.mjs --data ./data/idioms_500.json --review ./data/idiom_linguistic_review.csv` 嚴格驗證內容與簽核。
- [ ] 學段逐版課本證據另外管理；不得因正式題庫完成就宣稱 500 條全出現在各版本教材。

**交付**：審核合格的遊戲 JSON、法定授權標示、語文核對記錄、工具與實際驗證結果。
**門檻**：若尚無合法原始檔或尚未人工審校，M4 = `BLOCKED`；不得以 500 個詞目清單替代此門檻，也不得標記產品可正式上線。

## M5：相容性、品質、發布

**依賴**：M1–M4，且無 Critical blocker。

**任務**：
- [ ] 執行 Node 自動測試、`node codex-workpack/tools/check-release.mjs`、原生 HTTP 服務、子路徑資源測試、瀏覽器 console 檢查；發布工作流須以前述嚴格檢查成功為前置條件。
- [ ] iPadOS Safari、Android Chrome 實機測試：Start 權限、橫向兩種握法、校準、搖桿、P/R/A、連續遊玩穩定度。
- [ ] 在 4:3、16:10、16:9 核對 HUD 四格完整文字、注音、釋義、搖桿與觸控按鈕無交疊。
- [ ] 測試背景／縱向／系統來電／無感測器／拒絕授權／資料檔錯誤等異常情境。
- [ ] README 提供本地 `python -m http.server 8000` 等無依賴開啟方式及 Pages 部署方式。
- [ ] 完整填寫 `docs/ACCEPTANCE_MATRIX.md`、`docs/QA_DEVICE_MATRIX.md` 和 release checklist 的實測證據欄。
- [ ] 只有在授權、資料、功能、實機與部署均具備紀錄時才能標記 release-ready。

**交付**：可部署網站、所有測試證據、已知限制及釋出紀錄；沒有裝置則寫「未測」，沒有部署權限則寫「未部署」。

## 每階段通用守門條件

- **禁止自動宣告完成**：自動測試 PASS 只能證明它實際測到的項目。
- **不得修改硬參數**：如需調校，記錄建議與測試證據，僅調整規格允許的運動常數。
- **不可遺留關鍵空白實作**：沒有合法資料不得偽造；非關鍵實機驗收不足須準確標示。
- **每次任務摘要**：路徑、測試、狀態、風險及下一步，附上實際能重現的命令。
